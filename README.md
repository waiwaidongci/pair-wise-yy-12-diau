# hxyfront-62011 马术蹄铁修整档案

源提示词编号：6

做一个面向马术俱乐部蹄铁师的修蹄记录前端项目，可以记录马匹编号、步态问题、蹄形评估、蹄铁类型、钉位、修蹄日期、下次复查日期和照片备注。页面需要有马匹列表、复查提醒、左右前后蹄对比记录、异常步态标记和蹄铁更换历史。

## 技术栈

React + Vite + TypeScript

## 治疗与参赛放行台

在修蹄档案之外补充了蹄底脓肿治疗与参赛放行模块，记录、判断、页面三层分开：

- `src/domain/treatments.ts`（记录层）：治疗台账登记（马号、蹄位、药名、末次用药时间、退赛期）、同类药再用按更晚时间延长退赛窗口、更正留痕。
- `src/domain/clearance.ts`（判断层）：报名前先核对退赛期，再看赛前两次步态评估；期限没到或步态异常只能留在待复查；治疗记录新增/更正后原放行作废但保留旧结论。
- `src/pages/`（页面层）：治疗台账、参赛放行（可参赛/待复查名单）、更正与作废档案。
